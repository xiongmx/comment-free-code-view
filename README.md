# 显示/隐藏整行注释

在代码编辑器中右键选择 **“显示/隐藏整行注释”**，或按 `Ctrl+Shift+P`（macOS：`Cmd+Shift+P`）搜索并运行命令。第一次运行会隐藏整行注释，再运行一次即可显示。

只隐藏语法识别为注释、且整行（除空白外）都是注释内容的行；行尾注释、代码行内的块注释、字符串里的注释符号不会被隐藏。隐藏状态在同一文档的编辑器视图间共享；编辑文档时会重新识别并更新。**本功能仅改变编辑器中的文字显示，不编辑文档、不自动保存，也不读写剪贴板。** 隐藏的行会保留空白行位置和行号。

## 安装

需要 VS Code **1.99.0 或更高版本**，支持 Windows、macOS 和 Linux 桌面版。

1. 下载 `copy-clean-code-1.1.0.vsix`。
2. 打开 VS Code 的扩展视图，点击右上角 `…`。
3. 选择 **“从 VSIX 安装…” / “Install from VSIX…”**，选中该文件。
4. 打开代码文件，确认右下角的语言模式正确，再运行命令。

也可在终端执行：

```sh
code --install-extension copy-clean-code-1.1.0.vsix
```

本扩展未发布到扩展商店。语法和分词引擎都打包在安装文件中，不上传代码、不包含遥测。适用于本地、未信任工作区和虚拟文档；不是浏览器版 Web Extension。

## 支持的语言

注释识别依据 **VS Code 当前文档的语言模式 ID**，而不只看文件后缀。带注释的 JSON 可选择“JSON with Comments”。整行范围内的非空白字符都必须属于注释；因此普通代码中的行尾注释不会被隐藏。

| 语言模式 | 主要识别的注释形式 |
| --- | --- |
| JavaScript / TypeScript / JSX / TSX | `//`、`/* ... */`，区分字符串、模板字符串和常见正则字面量 |
| JSON / JSONC | JSONC 中的 `//`、`/* ... */`；普通 JSON 按对应语法处理 |
| C / C++ / C# / Java | `//`、`/* ... */`，字符串按各自语法处理 |
| Python | `#`；三引号字符串和 docstring 是字符串，不会作为注释处理 |
| Shell Script（Bash 语法） | `#`，区分引号字符串、常见参数展开和 here-document |
| YAML | `#`，区分引号字符串与块标量 |
| TOML | `#`，区分普通字符串和多行字符串 |
| SQL | 通用 SQL 语法中的 `--`、`/* ... */`；不承诺覆盖所有数据库方言 |
| HTML / XML | `<!-- ... -->`；HTML 内嵌脚本/样式由语法处理 |
| CSS | `/* ... */`；`//` 不是标准 CSS 注释 |
| SCSS / Less | 块注释及该语法支持的 `//` 注释 |
| PowerShell | `#`、`<# ... #>`，区分引号字符串和 here-string |
| Rust / Go | `//`、`/* ... */`，按语言语法区分字符串 |
| Nginx | `#`（仅引号外）；`//`、`/* ... */` 不是 Nginx 注释 |

Nginx 语言模式会自动匹配 `nginx.conf` 和 `.nginx`；普通 `.conf` 不会被自动指定为 Nginx。第三方 Nginx 语法扩展提供的 `nginx-conf` 和 `nginxconf` 模式也受支持。Nginx 中引号里的 `#`、转义哈希及参数内部的 `foo#bar` 会按原生 token 边界识别。

## 使用限制

- 隐藏的注释文字会透明显示，但所在行仍保留空白位置和行号；重新运行命令即可恢复。
- 语言范围来自扩展内打包的固定版本语法；Markdown、纯文本、自定义 DSL 和第三方自定义语法等不受支持。未支持语言会提示，且不会更改文档。
- 语法元数据无法覆盖所有语言方言和特殊语法。畸形或未闭合的代码可能受语法分词器局限。
- 注释中可能包含许可证、类型检查指令或格式化控制指令。隐藏不会删除这些内容，但隐藏状态不代表它们不影响代码工具。

## 源码构建与测试

构建环境需要 Node.js 20 或更高版本和 npm；运行 VS Code 集成测试还需要 Linux 的 Xvfb/桌面环境或对应系统的桌面环境。

```sh
npm ci
npm run build
npm test
npm run package
npm run test:integration
```

`npm run package` 使用 `@vscode/vsce` 生成 `artifacts/copy-clean-code-1.1.0.vsix`。集成测试会把 VSIX 安装到工程内独立的测试目录，不会安装到日常 VS Code 环境。
